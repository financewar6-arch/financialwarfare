# Financial Warfare - Morning Workflow Guide

**Your daily morning content operation in ~30 minutes.**

## The 30-Minute Morning Routine

### 7:00 AM - Log In & Review

```
1. Open Financial Warfare admin dashboard
   https://your-site.com/admin/pipeline

2. You see:
   ✅ 4 stories ready for review
   ✅ Scripts generated for all 5 platforms
   ⏱️ Estimated morning workflow time: 25 minutes
   
3. Current stories:
   🔥 NVDA +6.2% (Importance: 92)
   🔥 BTC -4.1% (Importance: 88)
   🔥 Oil +3.8% (Importance: 85)
   🟡 Fed Minutes (Importance: 72)
```

### 7:05-7:20 AM - Review & Approve

```
Go to: /admin/pipeline/review-scripts

For each story:
├─ Click story
├─ Review generated scripts
│  ├─ YouTube (30s)
│  ├─ TikTok (15s)
│  ├─ Instagram (30s)
│  ├─ LinkedIn (60s)
│  └─ Snapchat (10s)
├─ Read the script
├─ Check the hook (does it grab attention?)
├─ Verify facts (is it accurate?)
└─ Click ✅ APPROVE or EDIT or ❌ REJECT

QUICK EDITS YOU MIGHT MAKE:
├─ Change the hook phrasing
├─ Add/remove supporting detail
├─ Fix a fact or number
└─ Adjust the CTA (call-to-action)

To make an edit:
1. Click the script text
2. Edit inline
3. Click "Save Edit"
4. Approve

Total time: ~15 minutes for 4 stories
(~3-4 minutes per story)
```

### 7:20-7:25 AM - Batch Approve (Optional)

```
If you're happy with all 4:
Click: "Approve All Stories"

This moves all to the "videos ready" queue.

If you rejected any:
├─ System regenerates with feedback
└─ You review tomorrow
```

### 7:25-7:30 AM - Publish

```

```
1. Open /admin/pipeline/review-scripts

3. Click the HOOK text to edit
4. Change to: "Better hook here"
5. Click "Save"
6. Click "Approve"

### Scenario 3: "Fed Story Isn't Good Enough"
```
1. Open /admin/pipeline/review-scripts

```

   ├─ 08:00 AM (Video 1)

   ├─ 10:00 AM (Video 3)

## What Happens Overnight (Automated)

### 6:00 AM (GitHub Actions Runs)

**Step 1: Fetch News**
```
✓ Pulls financial news (last 16 hours)
✓ Checks 50+ news sources
✓ Fetches ~100-200 articles
```

**Step 2: Score Stories**
```
✓ Calculates importance for each story
✓ Ranks by:
  ├─ Market impact
  ├─ Recency
  ├─ Source quality
  ├─ Asset relevance
  └─ Engagement likelihood
```

**Step 3: Deduplicate**
```
✓ Groups identical stories (e.g., 10 sources saying "Nvidia up 6%")
✓ Keeps one story with multiple sources
✓ Reduces from 100 articles → 20-30 unique stories
```

**Step 4: Select Top Stories**
```
✓ Picks top 3-6 stories by importance
✓ Ensures diversity (not all crypto, not all tech)
✓ Checks: "Did we just cover this?"
✓ Avoids repetition
```

**Step 5: Generate Scripts**
```
✓ Calls Claude AI for each story
✓ Creates 5 platform-specific scripts:
  ├─ YouTube (30s, structured)
  ├─ TikTok (15s, snappy)
  ├─ Instagram (30s, visual)
  ├─ LinkedIn (60s, professional)
  └─ Snapchat (10s, casual)
```

**Step 6: Create Content Packages**
```
✓ Groups scripts for each story
✓ Ready for your review
✓ Marked as "READY FOR REVIEW"
```

**Step 7: Notification (Optional)**
```
✓ Email sent: "Morning content ready!"
✓ Or: Slack notification (when connected)
✓ Or: Just check the dashboard
```

## When Things Go Wrong

### Issue: "No stories generated"
```
Likely cause: News API down or no major stories
Action: 
1. Check NewsAPI status
2. Manually select 2-3 stories
3. Request scripts for those
4. Proceed normally
```

### Issue: "Script quality is bad"
```
Likely cause: Claude struggling with complex story
Action:
1. Click ✏️ Edit
2. Rewrite the hook
3. Click "Regenerate Script"
4. Or just reject and pick different story
```

### Issue: "Publishing failed to TikTok"
```
Likely cause: TikTok API rate limit or account issue
Action:
1. Check TikTok account status
2. Retry in 5 minutes
3. Or publish to other 4 platforms now
4. Retry TikTok later
5. System shows "Failed - Retry Available"
```

### Issue: "System is slow"
```
Likely cause: Too many API calls or regenerating
Action:
1. Refresh the page
2. Try again
3. Report the issue
(This shouldn't happen in normal usage)
```

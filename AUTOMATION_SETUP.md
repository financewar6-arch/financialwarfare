## 🔧 SETUP (One-Time, 5 minutes)

### Step 1: Verify Admin Token in Render

Go to render.com → Your Service → Environment

Verify you have:
  ADMIN_TOKEN = your-secret-token-123
  SITE_URL = https://yoursite.onrender.com

### Step 2: Create Daily Cron Job

Use EasyCron.com (free):

1. Sign up at easycron.com
2. Create new cron job:
   URL: https://yoursite.com/api/admin/auto-generate-editorial
   Headers: Add x-admin-token: your-admin-token-123
   Schedule: 0 6 * * * (6 AM daily)
3. Save and activate

That's it! ✓
